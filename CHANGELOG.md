# Changelog

All notable changes to **Termux-Sentry** will be documented in this file.

## [1.0.0] - 2026-09-02

### Added
- Linux `/sys/class/thermal` hardware zone reader with CPU/GPU throttling curves.
- Battery power telemetry profiler (bus voltage, mA discharge rate, live Watts).
- Process triage and active listening TCP/UDP socket radar.
- Cyberpunk ANSI CLI interface (`termux-sentry`, `sentry`).
- 1-Click Termux installer script (`termux/termux-install.sh`).
- Automated unit test suite and live web dashboard.
