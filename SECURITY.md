# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you identify a security issue in telemetry reporting or socket triage:
1. **Do not create a public GitHub issue.**
2. Email `security@veloriolabs.io`.
3. We will respond and provide an advisory within 48 hours.
